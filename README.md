## ✨ 这是什么

`lab-data-curve-fit` 是一个 Agent Skill（智能体技能包），把一次完整的实验数据拟合工作沉淀为可复用的工作流。它解决的问题非常具体：

- 实验教材给出 `y = a + bx^k` 这类公式，并指定了要试的若干个 k（例如 −1、−2、−4），手工逐个算最小二乘和相关系数既繁琐又容易算错；
- 实验数据处理软件虽然能给出 r、a、b 和不确定度，但它的出图没有刻度数值、没有单位、没有署名，达不到实验报告插图的要求；
- 拟合图里的文字框、图例很容易压住曲线或数据点，需要按数据走向选空白区域摆放。

本技能将整个流程标准化：**读数核对 → 公式线性化分诊 → 最小二乘 + 统计量交叉校验 → 出图 → 目视质检**，并对过程中的 10 余个易错点给出根因分析与标准解法。

首个落地案例：分光计测棱镜玻璃折射率的柯西色散拟合（汞灯 5 条谱线，n = a + b·λ^k，k = −1/−2/−4），27 项统计量与软件显示逐位一致。

## 🎯 使用场景

| 要素 | 说明 |
|---|---|
| 课程 | 大学物理实验、无机/分析化学实验等需要做函数拟合的课程 |
| 输入材料 | ① 实验数据表（截图 / 文本 / CSV，含单位）；② 待拟合公式（一个或多个）；③ 可选：软件已算出的 r、a、b 等，用于交叉校验 |
| 典型公式 | `y = a + bx`、`y = a + b·x^k`、`y = a + b·ln x`、`y = a·e^(bx)`、`y = a·x^b` |
| 质量要求 | 统计量口径与教材/软件一致；每个公式单独一张图；图内元素不遮挡数据；输出 600 dpi PNG + 矢量 PDF |

典型触发指令示例：

> 请根据我的实验数据，写一下函数拟合的 Python 程序，用于生成拟合图。需要分别拟合 3 个函数：y=a+bx^(-1)、y=a+bx^(-2)、y=a+bx^(-4)。

## 🚀 使用方法（工作流概览）

| 阶段 | 内容 | 关键点 |
|---|---|---|
| 0. 读数与核对 | 从截图/表格逐格读出 x、y 并回读复核，判断物理量与单位 | 数据零编造，单位存疑先问 |
| 1. 公式线性化分诊 | 查变换表把公式化为 `y = a + b·X` | 对 y 取对数的模型要写明 `Y = ln y` |
| 2. 拟合与统计量 | `polyfit` 求 a、b；算 r、S_y、s_a、s_b、u = t·s | 先用独立脚本与软件数值逐位比对，对不上不许交付 |
| 3. 出图 | 每公式一张图：空心数据点 + 600 点平滑曲线 + 结果框 + 图例 | 结果框、图例按空白象限摆放，不得遮挡 |
| 4. 质检 | 字形告警归零、数值一致、无遮挡、文件齐全 | 出图后自己看图自查 |

### 输入 / 产出

```
输入                              产出
─────────────────────────        ─────────────────────────────
实验数据（x, y + 单位）    ───▶    拟合脚本 .py（数据与公式写在顶部）
待拟合公式（1~N 个）        ───▶    每公式一张拟合图 .png(600dpi) / .pdf
软件已有结果（可选）        ───▶    多公式对比图 + 拟合结果汇总.txt

```

## 🔧 环境依赖

- **Python 3.9+**
- **numpy** —— 最小二乘 `polyfit`、相关系数 `corrcoef` 与残差统计
- **matplotlib** —— 出图（PNG 600 dpi + PDF 矢量）；中文字体需系统已装 PingFang SC / Hiragino Sans GB 等任一 CJK 字体
- 无图形界面环境可 `MPLBACKEND=Agg python3 xxx.py` 运行

安装：`python3 -m pip install numpy matplotlib`

## ⚠️ 重要说明

1. **数据零编造**：数据只能来自用户提供，单位存疑先确认，不得估算或补齐。
2. **统计量口径必须对齐教材/软件**：`ν = n−2`、`u = t·s`（P = 0.95，t 按 ν 查表）、`S_y` 分母为 `n−2`；禁止用 `scipy.optimize.curve_fit` 的协方差口径顶替。
3. **t 系数随数据点数变化**，换数据必须重算，不得沿用上次的值。
4. **一图一函数**：每个公式单独一张图，不额外并排"线性化对照面板"等子图。
5. **图内元素不得遮挡曲线与数据点**：先看数据走向，右上/左下（递减）或左上/右下（递增）为空白区，结果框与图例须分占不同象限。
6. **中文字形必须验证**：运行后确认无 `Glyph ... missing` 告警；`Å` 等特殊符号用 mathtext 写。
7. **出图后自己看图自查**，不把半成品丢给用户。
8. **单位与量级**：`b` 的量纲是 `y·x^(−k)`，换单位必须重算；引用 `b` 时须同时给出 x 的单位。

## 🐛 已知踩坑点（节选）

- 出双面板图（原始空间 + 线性化对照）被判多余 —— 只保留原始空间曲线一张图。
- 中文显示为方框 —— 设 `font.sans-serif` 回退列表 + `axes.unicode_minus = False`。
- 横轴单位 `Å`(U+00C5) 缺字形 —— 改用 `r"$\mathrm{\AA}$"`。
- 结果框压住拟合曲线中段 —— 按数据走向选空白象限，且与图例分占不同象限。
- 只连接数据点导致曲线像折线 —— 用 600 点 `linspace` 画连续曲线。
- 换单位后沿用旧的 `b` —— `b` 的量纲是 `y·x^(−k)`，必须重算。
- 无图形界面运行报错/挂起 —— 加 `MPLBACKEND=Agg`。
