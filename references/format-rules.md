# 格式硬规则、错误档案与用户偏好

## 一、格式硬规则

1. **一图一函数，不加多余面板**。每个公式单独一张图，只画原始变量空间（如 n～λ）的
   实验点 + 拟合曲线 + 结果框；**不要**额外并排"线性化对照图"子图。
   （来源：错误档案 #1，用户原话"右边那张去掉，多余了"）
2. **画布 9.4×6.4 英寸**，`constrained_layout=True`，标题 fontsize 17、轴标签 13。
   （来源：定稿 `scripts/cauchy_dispersion_fit.py`）
3. **数据点用空心圆**：`s=62, marker="o", facecolors="white", edgecolors=<主题色>, linewidths=1.8`。
   拟合曲线用红色 `#d62728`、`linewidth=2.0`、600 个采样点。
4. **曲线范围略超数据区间**：`np.linspace(x.min()*0.985, x.max()*1.015, 600)`，
   避免曲线在数据点处"断头"。
5. **纵轴留白**：`y_pad = (ymax-ymin)*0.10`，`ylim = (ymin-y_pad, ymax+y_pad*1.6)`
   （上方多留，给结果框腾位置）。
6. **中文字体必须验证**：`plt.rcParams["font.sans-serif"]` 按
   `Hiragino Sans GB / Microsoft YaHei / SimHei / PingFang SC / Noto Sans CJK SC / Source Han Sans SC / Arial Unicode MS`
   顺序自动回退；`axes.unicode_minus = False`。运行后**看告警**，缺字形必须换写法（见 #2）。
7. **特殊单位符号用 mathtext**：`Å` 写成 `r"波长 $\lambda$ / $\mathrm{\AA}$"`，
   因为中文字体不含 U+00C5 字形。（来源：错误档案 #2，自查）
8. **图内结果框逐项对齐软件显示项**：署名 / 函数关系式 / 相关系数 r / Y的标准偏差 /
   系数 a / a 的标准偏差 / a 的 A 类不确定度分量 / 系数 b / b 的标准偏差 / b 的不确定度。
9. **输出双格式**：600 dpi PNG + 矢量 PDF；路径用
   `os.path.dirname(os.path.abspath(__file__))` 固定到脚本所在目录。
10. **结果同步落盘** `拟合结果汇总.txt`（原始数据 + 三组统计 + 残差 + 结论）。
11. **署名写进脚本顶部常量**（`STUDENT`），不要散落在多处。
12. **中间产物进 `.workbuddy/`**，交付物落在脚本所在目录；交付后更新记忆日志。

## 二、错误档案

| # | 犯过的错误 | 用户反馈（保留原话） | 正确做法 |
|---|---|---|---|
| 1 | 出图时做成"左 n～λ 曲线 + 右线性化 n～λ^k"双面板，自认为更完整 | "前三张拟合图右边那张去掉，多余了。仅保留左边的即可。" | 每个公式只出一张原始空间曲线图；线性化过程体现在脚本与说明里，不占版面。删掉子图后同步放大画幅与字号（58→62、10.5→11） |
| 2 | 横轴单位直接写 `Å`（U+00C5），中文字体无此字形 | （自查发现，无用户反馈）运行告警：`Glyph 197 (\N{LATIN CAPITAL LETTER A WITH RING ABOVE}) missing from font(s) Hiragino Sans GB` | 改用 mathtext：`r"波长 $\lambda$ / $\mathrm{\AA}$"`；运行后 `grep -i glyph` 必须归零 |
| 3 | 图内结果框放在左上角，压住左上角数据点 | （自查发现，无用户反馈） | 先判断数据走向，再选空白象限 |
| 4 | 结果框从左上角改到 `x=0.32` 后，压住了红色拟合曲线的中段 | （自查发现，无用户反馈；视觉检查发现） | n～λ 图数据自左上降到右下 → 空白区是**右上**与**左下**：结果框放右上（`0.97, 0.97, ha="right"`），图例放左下 |
| 5 | 对比图参数表放左上角，同时压住左上角数据点并与右上角图例相撞 | （自查发现，无用户反馈） | 参数表移到右上（`ha="right"`）、图例移到左下；图例再放右上会与表格重叠 |
| 6 | 生成文件名时打算把 `k-1` 里的 `-` 替换成 `_m`（`dispersion_k_m1`） | （自查发现，无用户反馈） | 直接 `f"dispersion_k{k}_n_lambda"`；连字符在文件名里可读，不要为了"顺眼"二次加工 |

## 三、用户偏好（协作方式）

- **极简优先**：同一信息只呈现一次；"多余"的子图、面板、装饰一律不要加。
- **汇报要点化**：「改了什么 → 数值是否仍与软件一致 → 目视检查结论」，不要长篇。
- **沿用既有基线**：用户会给出一份自己满意的参考脚本，风格照抄（字体列表、
  600 dpi + PDF、图内结果框、署名），不要另起炉灶。
- **小步微调**：用户会给出精确数值指令（画布、字号、位移），照数执行，不要顺手改别的。
- **先验证再交付**：出图后自己看图自查，不许让用户当 QA。
- **交付即可用**：脚本必须能直接跑，运行命令写进文件头注释。

## 四、方法论内核（原始 Prompt 分诊）

原始 Prompt 三条内容：① 根据实验数据写函数拟合 Python 程序；② 分别拟合 3 个函数；
③ 附参考脚本 `~/Documents/michelson_fit.py` 作为风格要求。

**保留**：
- 「数据 + 公式 → 脚本 + 拟合图」的任务定义；
- 多公式**分别**出图（不是叠在一张图里），额外再给一张对比图；
- 参考脚本作为风格基线。

**显式弃用**：
- 用户贴的「指定函数的拟合结果」软件截图（左栏数值 + 右栏无刻度的 X/Y 曲线）
  **只作为数值校验基准**，其版式**不再采用**——该图无刻度数值、无单位、无署名，
  达不到实验报告插图要求；最终交付采用带刻度、带单位、带结果框与署名的单面板图。
- 参考脚本中"只在数据点之间连线"的画法不适用于非线性模型，改为 600 点连续曲线。
